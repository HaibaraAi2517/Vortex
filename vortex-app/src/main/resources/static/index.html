      接入你的 Agent

      在 Agent 所用的 Python 环境中安装 Vortex（Python 3.10 或更高版本）。使用期间保持本地服务运行。

      从下载的 ZIP 安装

      在解压后的文件夹打开 PowerShell。只用 Python SDK，执行前两行；接入 MCP 客户端，再执行第三行。

      $wheel = (Get-ChildItem -LiteralPath .\python -File -Filter '*.whl').FullName
python -m pip install "$wheel"
python -m pip install "${wheel}[mcp]"
      从源码仓库安装

      在仓库根目录执行。只用 Python SDK 可以省略 [mcp]。

      python -m pip install "./sdk/python[mcp]"

      在 Python 中检索

      连接 MCP 客户端（stdio）

      在刚才安装的环境中运行这条命令。

      python -c "import sys; print(sys.executable)"

      支持 JSON 的客户端可使用下列配置。其他客户端可分别填写启动命令、参数和环境变量。已启用鉴权的服务还需设置 VORTEX_SECURITY_BEARER_TOKEN。
