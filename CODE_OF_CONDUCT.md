# Code Of Conduct

Vortex aims to be a practical, evidence-driven engineering project. Discussion
should stay respectful, specific, and useful to the work.

## Expected Behavior

- Be direct about technical tradeoffs while staying civil.
- Assume good faith, but ask for evidence when claims affect design,
  benchmarks, reliability, or public positioning.
- Keep issues and pull requests focused on reproducible behavior, concrete
  requirements, or maintainable implementation choices.
- Credit prior work and be clear when a contribution depends on third-party
  code, models, datasets, or services.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without explicit permission.
- Spam, trolling, or repeated off-topic comments.
- Fabricating benchmark results, test coverage, production usage, or other
  project evidence.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or other
contributions that violate this code of conduct. Serious or repeated violations
may result in a temporary or permanent ban from project spaces.

To report a concern, open a private communication channel with the maintainer if
one is available, or use the least public channel that still allows maintainers
to respond. Reports should include links, screenshots, logs, or other concrete
context where possible.
