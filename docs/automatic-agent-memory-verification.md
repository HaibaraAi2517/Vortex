## 验证范围

- 无记忆 namespace 的模型明确回答不知道。
- Python 从普通陈述中提取北京和无糖美式，创建两个 v1 事实。
- Spring AI 在新 JVM 中读取旧事实，再从用户的变化陈述中提交上海和燕麦拿铁两个 v2 事实。
- 全新的 Python 和 Spring AI 会话都回答最新城市和偏好；检索结果不含旧住址。
- 朋友住址、朋友偏好和可能的出差计划没有被写入用户的长期事实。
- 问句不会创建新版本；历史各保留 v1 和 v2。
- 官方 MCP Client 通过 stdio 成功读取同一套更新后的事实，get_memory 返回 v2。
- 29 个 Python/MCP 测试和 12 个 Spring AI 测试通过。Spring AI 测试包括真实 ChatClient Advisor 链、大小写结束状态、取消/失败流不写入、完整流只写入一次。
