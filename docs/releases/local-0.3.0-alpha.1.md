# Vortex 个人记忆工作台 · 首个 Windows x64 预览版

Windows x64 用户下载 `vortex-local-windows-x64.zip`，完整解压后双击 `Start Vortex.cmd`。Java 21 和本地检索模型已包含在包内。工作台就绪后会打开浏览器。新安装的数据位于 `%LOCALAPPDATA%\Vortex\data`，启动窗口会显示实际位置。

点击「运行真实演示」，工作台会在独立空间依次保存北京和上海。点击「当前住所」，勾选要提供的资料，预览后点击「复制任务和所选记忆」。将整条消息粘贴到豆包的新对话即可试用。Codex CLI 可通过随包的 MCP 适配器直接读写同一空间，安装命令在工作台的「接入你的 Agent」中。

## 一次真实的跨会话测试

2026 年 11 月 20 日，在 Windows 上运行解压出的服务和随包 Python wheel。两个新建的 Codex CLI 会话共用一个空白测试空间，分别使用独立的临时对话目录，仅启用 Vortex MCP。以下是该次运行的实际结果。

| 客户端 | 用户输入或操作 | 实际结果 |
| --- | --- | --- |
| Codex，会话一 | 我平时最喜欢喝青柚美式。 | 先查当前事实，再调用 `remember`，写入第 1 版。 |
| Python SDK | 把这项偏好更新为「我现在最喜欢喝榛果燕麦拿铁。」 | 根据第 1 版写入成功，服务返回第 2 版。 |
| Codex，会话二 | 我平时最喜欢喝哪种咖啡？只告诉我现在的偏好。 | 调用 `get_memory`，回答「榛果燕麦拿铁。」 |

这次验收覆盖一个用户的一项偏好。自动从自然语言判断事实归属还会受措辞和所选模型影响。网页复制由用户确认发送，接收方能看到所选资料。此版本面向个人电脑，默认只监听本机回环地址。

升级前请停止旧服务并备份启动窗口显示的数据目录，再将新版解压到另一文件夹。[数据目录与备份](../local-memory.md#持久化边界与备份)
