# Vortex v0.1.0 Release Notes

Released: 2026-08-01

Vortex v0.1.0 is the stable portfolio baseline for the memory, hybrid
retrieval, and runtime-recovery kernel. The tag identifies a reproducible
code-review and local-evaluation point; it is not a claim that Vortex is a
production-ready hosted service.

The original [v0.1.0-alpha notes](v0.1.0-alpha.md) remain archived. The alpha
tag is not moved or rewritten.

## Release Focus

- An interviewer-first README with one system diagram, one-command Quickstart,
  and three explicit engineering decisions with trade-offs and evidence.
- L1 Caffeine write-through with bounded asynchronous L2 Milvus indexing and
  L3 MinIO archival.
- Case-isolated hybrid-retrieval evaluation and frozen model-promotion gates.
- Snapshot, WAL replay, and Execution ID idempotency for deterministic runtime
  recovery.
- Optional LangChain4j ChatModel and EmbeddingModel adapters.
- A tracked local BGE model and a real ONNX Cross-Encoder smoke test in the
  default Maven test path.

## Evidence-Backed Results

| Area | Result |
| --- | --- |
| Main-path latency | P99 `818.82 ms` to `268.65 ms` (`-67.19%`) over 100 cases per mode; L1 visibility and eventual L2/L3 readiness were `100%` |
| LongMemEval recall | Case-isolated fragment Recall@5 `0.8094`, `+0.1856` over KeywordOnly, paired 95% CI `[+0.1086, +0.2632]` |
| Runtime recovery | `32/32` deterministic fault-injection cases passed across five failure categories |
| Cross-Encoder gate | The pinned DEV candidate changed `120/120` rankings but failed the frozen quality/latency gate; VectorOnly remains default |

See [docs/benchmark.md](../benchmark.md) for exact scope, reproduction paths,
and the distinction between deterministic local results and production claims.

## Quick Start

PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\examples\quickstart-agent\run.ps1 -StartQuickstart
```

Linux/macOS:

```bash
START_QUICKSTART=true bash examples/quickstart-agent/run.sh
```

The demo requires no external LLM API key and exercises memory recall plus
checkpoint recovery after a worker process is killed.

## Release Verification

The release commit was verified on Windows with Docker Desktop:

```powershell
mvn -B clean verify
mvn -B org.jacoco:jacoco-maven-plugin:0.8.15:prepare-agent test org.jacoco:jacoco-maven-plugin:0.8.15:report
powershell -NoProfile -ExecutionPolicy Bypass -File .\examples\quickstart-agent\run.ps1 -StartQuickstart
```

Results:

- `548` tests, `0` failures, `0` errors, and `0` skipped.
- App Docker integration suite: `13/13` passed.
- JaCoCo aggregate line coverage: `74.25%` across five code modules.
- Quickstart built the stable `0.1.0` image, recalled durable memory, killed a
  worker after checkpointing, recovered `nodeCount=1`, and continued execution.
- Compose containers were removed after verification; named volumes were kept.

## Compatibility Notes

- Maven artifacts now use version `0.1.0` instead of `0.1.0-SNAPSHOT`.
- Docker, demo, governance, and eval scripts use the stable artifact names.
- The REST surface remains a `0.x` API and may evolve in later releases.

## Known Boundaries

- No production-grade auth, RBAC, tenant isolation, rate limiting, or audit log.
- No distributed consensus, multi-node scheduling, or cross-region replication.
- Main-path latency excludes external LLM generation.
- LongMemEval Recall@5 measures oracle-fragment retrieval, not final-answer
  accuracy.
